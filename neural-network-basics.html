Neural networks, one neuron at a time

A neural network is a stack of very small calculations whose numbers are tuned until the output is useful. This page builds one from the ground up, and every diagram that has sliders is live.

The idea in three sentences

A neural network takes numbers in, pushes them through layers of simple units, and produces numbers out. At first its output is wrong, because its internal settings (called weights and biases) are random. Training repeatedly measures how wrong it is and nudges every weight in the direction that makes it less wrong.

So the whole subject boils down to a loop:

  1. Predict. Run the input forward through the network (the forward pass).
  2. Measure. Compare the prediction to the correct answer with a loss function.
  3. Blame. Work out how much each weight contributed to the error (backpropagation).
  4. Adjust. Move each weight a little to reduce the error (optimization).

The rest of this page takes each piece in turn.

The neuron: a weighted vote

The building block is the node (or neuron, or unit). It does three things: multiply each input by a weight, add everything up together with a bias, and pass the total through an activation function.

z = w₁·x₁ + w₂·x₂ + … + wₙ·xₙ + b (weighted sum, "pre-activation") a = f(z) (output, "activation")
  • Inputs (x) are numbers coming in: pixel brightness, a price, or the outputs of the previous layer.
  • Weights (w) say how much each input matters and in which direction. A large positive weight means "this input pushes me to fire"; a negative weight means "this input suppresses me". Weights are the thing the network learns.
  • Bias (b) shifts the neuron's threshold. With a bias of −2 the weighted sum must reach 2 before the neuron starts to respond. Without a bias, every neuron would be forced to pass through the origin.
  • Activation function (f) bends the result. It is what lets networks represent more than straight lines (more in the activation section).

A neuron with a sigmoid activation is essentially logistic regression, and one with no activation is linear regression. A neural network is many of these wired together.

Layers: stacking neurons

Neurons are grouped into layers. Every neuron in a layer sees the same inputs but has its own weights, so each one can learn to detect something different.

Input layer
Holds the raw features. It does no computation; it simply presents the data. One node per feature (a 28×28 image gives 784 input nodes).
Hidden layers
Everything between input and output. "Hidden" only means you don't directly observe their values. Early hidden layers tend to learn simple patterns, later ones combine them into more abstract ones (edges, then shapes, then objects).
Output layer
Produces the answer in the form the task needs. Its size and activation depend on the problem.

Depth is the number of layers, and width is the number of neurons per layer. A network with many hidden layers is a deep network, which is where the term deep learning comes from. A layer where every neuron connects to every neuron in the previous layer is called dense or fully connected.

Feed forward: what it means

A feedforward network is one where information moves in a single direction: input, then hidden layers, then output. There are no loops and no connection that feeds an output back into an earlier layer. Running data through it in that direction is the forward pass (also called inference when you are only predicting and not training).

Each layer's output becomes the next layer's input. In matrix form, one layer is:

a⁽ˡ⁾ = f( W⁽ˡ⁾ · a⁽ˡ⁻¹⁾ + b⁽ˡ⁾ ) a⁽⁰⁾ = x (the input) ŷ = a⁽ᴸ⁾ (the output of the last layer)

Shapes matter here. If a layer has 4 inputs and 3 neurons, W is 3×4, b has length 3, and the output has length 3. Processing a whole batch of examples at once just means the input becomes a matrix (one row per example), which is why GPUs, which are very good at matrix multiplication, make training fast.

Feedforward contrasts with recurrent networks, which keep a hidden state that loops back to themselves so they can process sequences. Even then, the basic building block is the same weighted sum plus activation.

Activation functions: where the power comes from

Without activation functions, a network could only compute straight-line relationships. Stacking linear steps gives another linear step: W₂(W₁x) = (W₂W₁)x, which is just one layer in disguise. A non-linear activation between layers breaks that collapse, so each extra layer can bend the function further. That is what allows a network to learn things like XOR, curved boundaries, and images.

Good activation functions are non-linear, cheap to compute, and differentiable (almost everywhere), because backpropagation needs their slope.

Activation function plotter

Solid blue is the function, dashed amber is its derivative (the slope that gradients get multiplied by during learning).

Which one should I use?

  • Hidden layers: start with ReLU. It is simple, fast, and works well in most networks. If many neurons die (always output 0), try Leaky ReLU or SiLU/GELU. Transformers typically use GELU or SiLU variants.
  • Binary output: sigmoid gives a number between 0 and 1 you can read as a probability.
  • Multi-class output: softmax, described next.
  • Regression output: no activation, so the output can be any real number.

Softmax: turning scores into probabilities

For a multi-class output, the last layer produces raw scores called logits. Softmax exponentiates each one and divides by the total so that the results are positive and sum to 1:

softmax(zᵢ) = e^zᵢ / Σⱼ e^zⱼ

Softmax

Raise one logit and the others lose probability, because they must always sum to 100%.

Loss: a single number for "how wrong"

To improve, the network needs a score. The loss function (cost function, objective) compares the prediction ŷ with the true value y and returns one number, where lower is better. Training is the search for weights that minimise the average loss over the training data.

Mean squared error(y − ŷ)²Regression. Penalises large errors heavily.

Categorical cross-entropy−Σ yᵢ·ln ŷᵢMulti-class problems with softmax output.

Backpropagation: assigning blame

The loss tells us the network is wrong but not which weights to change. Backpropagation answers that by computing the gradient: for every weight, the partial derivative ∂L/∂w, which says how much the loss would change if that weight increased a little.

It works by applying the chain rule from calculus backwards through the network. Starting at the loss, it passes the error signal back layer by layer, reusing what it computed on the forward pass. For one neuron with z = wx + b and a = f(z):

∂L/∂w = ∂L/∂a · ∂a/∂z · ∂z/∂w = (loss slope) · f′(z) · x ∂L/∂b = ∂L/∂a · f′(z) · 1

Three consequences are worth remembering. The gradient of a weight is large when the input feeding it was large. It is scaled by the activation's derivative, so saturated sigmoids pass back almost nothing. And it is multiplied layer after layer, which is why deep networks can suffer from vanishing or exploding gradients (covered below).

Optimization: using the gradient

The gradient points uphill, so we step the opposite way. This is gradient descent:

w ← w − η · ∂L/∂w (η = learning rate)

Picture the loss as a landscape over all the weights. Gradient descent is a walker in fog who can only feel the slope under their feet and takes a step downhill each time. The learning rate η is the step size, and it is the most important hyperparameter you will tune. Too small and training crawls; too large and you overshoot the valley and bounce or diverge.

Gradient descent on a bumpy loss

This loss has a shallow valley on the right (a local minimum) and a deeper one on the left (the global minimum). Pick a starting point and learning rate, then step. Try starting at +2, then −2, then raise the rate above 1.

Batches and epochs

  • Batch gradient descent computes the gradient over the whole dataset before each update. Accurate but slow.
  • Stochastic gradient descent (SGD) updates after every single example. Fast but noisy.
  • Mini-batch uses small groups (commonly 32 to 256). It is the practical default, balancing speed, stability and hardware efficiency. The noise even helps escape shallow local minima.
  • One full pass over the training data is an epoch. Training usually runs for many epochs.

Better optimizers

Plain SGD struggles in landscapes shaped like a long, narrow valley: it zig-zags across the steep walls while crawling along the gentle floor. Modern optimizers fix this by remembering past gradients or by adapting the step size for each weight.

OptimizerIdeaNotes
SGDStep straight down the current gradient.Simple, well understood, needs careful learning-rate tuning.
SGD + momentumKeep a running average of gradients, like a ball gaining speed rolling downhill.Damps zig-zag and speeds up along consistent directions. Typical momentum is 0.9.
RMSpropDivide the step by a running average of recent squared gradients.Weights with big gradients take smaller steps, rarely-updated ones take larger steps.

Learning-rate schedules

Many training runs start with a large learning rate for quick progress, then shrink it so the weights can settle into a minimum. Common patterns are step decay, cosine decay, and a short warm-up at the start (standard for transformers).

Making it work in practice

Initialisation

Weights cannot all start at zero, because then every neuron in a layer computes the same thing and receives the same gradient, so they never become different. Weights start as small random numbers, scaled by layer size: Xavier/Glorot initialisation for tanh and sigmoid, He initialisation for ReLU. Biases usually start at zero.

Vanishing and exploding gradients

Backprop multiplies many numbers together. The sigmoid's slope is at most 0.25, so after ten sigmoid layers the gradient can shrink by a factor of 0.25¹⁰, roughly one in a million. Early layers then barely learn: vanishing gradients. If the multiplied factors are instead above 1, gradients blow up: exploding gradients. The standard remedies are ReLU-style activations, careful initialisation, normalisation layers, residual (skip) connections, and gradient clipping.

Data splits and overfitting

A network with enough parameters can memorise the training set, including its noise. This is overfitting: training loss keeps falling while performance on new data gets worse. The opposite, underfitting, is a model too simple to capture the pattern at all.

  • Training set fits the weights.
  • Validation set is used to tune hyperparameters and decide when to stop.
  • Test set is touched once at the end for an honest estimate of real-world performance.

Regularisation: fighting overfitting

  • More (or augmented) data. The most reliable fix. Flip, crop or perturb examples to create variety.
  • L2 / weight decay. Adds a penalty on large weights so the model prefers simpler solutions. L1 pushes weights to exactly zero.
  • Dropout. Randomly switches off a fraction of neurons during each training step so none can rely on a specific partner.
  • Early stopping. Stop when validation loss stops improving.
  • Smaller model. Fewer layers or units.
  • Batch / layer normalisation. Rescales activations inside the network. It mainly stabilises and speeds up training, with a mild regularising side effect.

Hyperparameters to tune

These are settings you choose rather than learn: learning rate (first, always), batch size, number of layers and units, activation functions, optimizer, regularisation strength, dropout rate, and number of epochs. Change one at a time, and judge by validation performance.

The same loop in code

import torch, torch.nn as nn

model = nn.Sequential(
    nn.Linear(2, 8), nn.ReLU(),        # hidden layer 1
    nn.Linear(8, 8), nn.ReLU(),        # hidden layer 2
    nn.Linear(8, 1), nn.Sigmoid(),     # output layer
)
loss_fn = nn.BCELoss()
opt = torch.optim.Adam(model.parameters(), lr=1e-3)

for epoch in range(100):
    for xb, yb in loader:              # mini-batches
        pred = model(xb)               # 1. forward pass
        loss = loss_fn(pred, yb)       # 2. measure error
        opt.zero_grad()
        loss.backward()                # 3. backpropagation
        opt.step()                     # 4. update weights

Beyond the basic network

The feedforward network with dense layers is called a multilayer perceptron (MLP). Most other architectures keep the same ingredients (weights, activations, loss, gradient descent) and change how the neurons are wired.

Convolutional networks (CNNs)
Slide small shared filters across an image, so the same edge detector is reused everywhere. Far fewer parameters than dense layers, and built-in awareness of spatial structure.
Recurrent networks (RNNs, LSTMs, GRUs)
Carry a hidden state from one step of a sequence to the next. Designed for text, audio and time series, though largely replaced by transformers for language.
Transformers
Use attention to let every element of a sequence look at every other element directly. The basis of modern language models and increasingly used for images and audio.
Autoencoders
Compress the input into a small code, then reconstruct it. Used for compression, denoising and anomaly detection.
Generative models (GANs, diffusion models, VAEs)
Learn to produce new data resembling the training data.

Glossary

Activation
A neuron's output after applying the activation function to z.
Backpropagation
The algorithm that computes gradients of the loss with respect to every weight using the chain rule.
Batch size
Number of examples used for one weight update.
Bias
A learnable offset added to a neuron's weighted sum.
Epoch
One complete pass through the training data.
Feedforward
Data flows strictly from input to output with no cycles.
Gradient
The vector of partial derivatives showing how the loss changes with each parameter.
Hyperparameter
A setting chosen by the practitioner, not learned from data.
Learning rate
The step size of each weight update.
Logit
A raw, unnormalised output score before sigmoid or softmax.
Loss
A number measuring the difference between predictions and targets.
Overfitting
Fitting training data so closely that performance on new data suffers.
Parameter
Anything learned during training: weights and biases.
Weight
A learnable multiplier on a connection between two neurons.
